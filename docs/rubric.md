# 五维成长 rubric

成长报告只做一件事：把会话卡里的行为证据，映射到五个维度上，并明确说出“证据不足”和“与判断相反”的部分。

## 通用规则

1. **只依据会话卡和卡片里的原话**，不补充外部事实，不做心理诊断，不贴人格标签。
2. 每条判断都要有 `quote` + `session_id` + `message_id`；引用必须能在原消息里逐字找到，否则被剔除。
3. 只把**用户说出口的**当成证据；助手说的话只用于理解上下文。
4. 必须写 `counter_evidence`：与判断相反或不适用的情况；没有就写“暂未发现”。
5. `score` 允许为 `null`。`null` 表示证据不足，不是 0 分。
6. 变化必须和上一期对比；没有上一期就写 `no_baseline`，不要编造进步。

## 评分锚点

| 分数 | 含义 |
| --- | --- |
| 1 | 几乎没有相关证据，主要依赖直觉或外部答案 |
| 2 | 偶有意识，但不稳定 |
| 3 | 能主动使用，但缺少系统性 |
| 4 | 稳定使用，能在复杂情境中调整 |
| 5 | 形成方法论，能迁移并教给别人 |
| null | 证据不足，不打分 |

## 1. 技术判断力

看什么：约束识别、权衡维度、风险预判、对 hype 的抵抗、预测与结果是否一致。

- 能否说出“在什么约束下这个方案才成立”？
- 有没有把“流行”当成“适合”？
- 事前的预测和事后的结果是否对得上？

## 2. 决策质量

看什么：选项完整性、可逆/不可逆判断、信息收集、决策标准、承诺与复盘。

- 有没有比较过不止一个选项？有没有说清放弃的理由？
- 是否区分了可逆决定和不可逆决定（前者应该更快）？
- 说要做的事，后来做了吗？

## 3. 研究方法

看什么：问题定义、假设是否可证伪、变量控制、证据等级、反例意识。

- 问题是“能不能做成”还是“值不值得做”？
- 假设能不能被一次实验推翻？
- 有没有主动找反例，而不是只找支持自己的材料？

## 4. 逻辑语言能力

看什么：概念定义、事实/推断/价值分离、因果 vs 相关、限定条件、绝对化表达、类比质量、自我修正的语言标记。

- “一定”“肯定”“所有人都”这类绝对化表达出现时，有没有限定？
- 是在描述事实，还是在表达偏好？
- 修正自己时用的是“我原以为…”还是直接换话题？

## 5. 思维认知方式

看什么：抽象层级、框架来源与迁移、二元对立/过度概括、自我修正的触发方式、注意力分配。

- 讨论停留在具体操作，还是能上升到可复用的框架？
- 框架是从哪来的？能不能迁移到别的领域？
- 什么情况下会触发自我修正：被质疑、遇到反例，还是自己主动检查？

## 基线与趋势

- **基线不打分**：第一次全量回看只建立起点，五个维度全部为 `null`，`change = no_baseline`。
- **每两个周日出一次成长报告**；判定窗口用 13 天，避免周日任务漂移到第三周。
- **满 3 个点（6 周）才标“趋势”**。两个点只能叫“变化”。

## L4 复核

已确认的自我认知会在下一次成长报告里逐条复核：

| verdict | 含义 |
| --- | --- |
| `confirmed` | 这一期仍有支持证据 |
| `weakened` | 证据变弱，但仍存在 |
| `contradicted` | 出现反例 |
| `insufficient` | 这一期找不到可回链的证据 |
| `revisit` | 被驳回的判断出现了强新证据，值得重看 |

被驳回的判断不会原样重提；来源修正（`kind = note`）只用于提醒模型不要错误归属，不作为特质使用。
